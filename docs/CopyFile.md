# 复制文件/目录 (CopyFile)

## 1. 功能概述
将指定文件或文件夹完整复制到新位置，支持单文件拷贝与目录树递归复制，支持重命名。

## 2. 核心特性
- **递归完整拷贝**：支持单个文件复制或整目录及其所有子项完整拷贝。
- **智能重命名**：可选指定新文件名，未指定时默认保持原始名称。
- **安全防护**：内置路径有效性检测与越界保护。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `from` | `MixedType` | `""` | 要复制的源文件或源目录路径 |
| `to` | `MixedType` | `""` | 目标存储目录或文件目的路径 |
| `filename` | `MixedType` | `""` | 重命名新文件名（留空则保持原文件名） |

## 4. 输出
- 返回操作是否成功布尔值（`bool`）。
