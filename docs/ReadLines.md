# 按行读取文本 (ReadLines)

## 1. 功能概述
读取本地文本文件并按换行符（`\r\n` 或 `\n`）拆解为字符串数组列表，适用于大文本日志解析与批量数据行读取。

## 2. 核心特性
- **高效逐行解析**：大文件流式按行切割，避免整文件一次性加载过大内存开销。
- **异步非阻塞**：支持后台异步非阻塞模式执行分片按行读取。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `file` | `MixedType` | `""` | 待读取的目标文本文件路径 |
| `async` | `MixedType` | `false` | 是否启用后台异步读取模式 |

## 4. 输出
- 返回按行分割后的字符串数组列表（`Array`）。
