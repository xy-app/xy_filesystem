# 加载图像数据 (ImageLoad)

## 1. 功能概述
从本地电脑磁盘读取并打开图片文件，解码为可在下游机器视觉与自动化流程中流转的内存图像对象。

## 2. 核心特性
- **主流图像格式**：支持 PNG、JPEG、BMP、WebP 等常用图片格式的快速加载。
- **零损耗内存对象**：直接解码为 `Image` 内存对象，便于衔接模板匹配与找色动作。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `file` | `MixedType` | `""` | 本地磁盘图像文件的完整路径 |

## 4. 输出
- 返回解码后的内存图像对象（`Image`）。
