# 查询文件属性/匹配 (FileQuery)

## 1. 功能概述
快速检查本地文件系统元数据，查询指定文件或文件夹是否存在、获取文件大小或进行通配符规则匹配。

## 2. 核心特性
- **多维度状态检测**：支持 `exists`（存在性）、`size`（文件大小）、`is_dir`（是否为目录）、`is_file`（是否为文件）。
- **通配匹配支持**：支持通配符规则过滤与路径存在性校验。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `pattern` | `MixedType` | `""` | 目标文件路径或通配符表达式 |
| `option` | `MixedType` | `"exists"` | 查询类型（`exists`, `size`, `is_dir`, `is_file`） |

## 4. 输出
- 返回查询结果字符串（`string`，根据选项返回布尔状态或字节大小）。
