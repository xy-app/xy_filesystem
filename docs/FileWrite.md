# 写入文件内容 (FileWrite)

## 1. 功能概述
将文本字符串或数据持久化保存到电脑本地磁盘文件，支持覆盖或追加模式。

## 2. 核心特性
- **目录自动创建**：若目标输出文件夹不存在，自动创建对应父级目录。
- **自定义命名**：支持指定文件名，留空时支持自动按时间戳命名。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `folder` | `MixedType` | `""` | 输出存储的父文件夹目录路径 |
| `filename` | `MixedType` | `"output.txt"` | 写入目标文件的文件名（含扩展名） |
| `source` | `MixedType` | `""` | 待持久化写入的文本或数据内容 |

## 4. 输出
- 返回写入是否成功布尔值（`bool`）。
