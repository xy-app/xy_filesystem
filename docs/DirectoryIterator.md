# 遍历目录文件 (DirectoryIterator)

## 1. 功能概述
遍历扫描指定本地文件夹下的所有文件和子目录列表，支持多扩展名过滤与递归深度扫描。

## 2. 核心特性
- **递归与单层遍历**：自由切换仅扫描当前层级或深度向下递归遍历多级子目录。
- **扩展名通配过滤**：支持 `*`、`txt`、`png,jpg`、`*.csv` 等多种扩展名后缀过滤。
- **异步非阻塞**：支持后台异步非阻塞模式执行遍历任务。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `path` | `MixedType` | `""` | 待遍历的目标根目录路径 |
| `recursive` | `MixedType` | `false` | 是否递归查找子目录 |
| `extensions` | `MixedType` | `"*"` | 扩展名过滤规则（如 `*` 或 `txt;png`） |
| `async` | `MixedType` | `false` | 是否启用后台异步遍历模式 |

## 4. 输出
- 返回遍历到的所有文件绝对路径数组列表（`Array`）。
