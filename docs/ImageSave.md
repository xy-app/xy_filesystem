# 保存图像文件 (ImageSave)

## 1. 功能概述
将当前内存中的 Image 图像对象编码并持久化保存至本地磁盘文件中。

## 2. 核心特性
- **视觉流水线持久化**：无缝接收屏幕截屏或视觉处理输出的内存图像对象并落盘。
- **自动格式转换**：根据指定文件后缀（如 `.png`, `.jpg`, `.pdf`）自动选择相应编码格式保存。

## 3. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `folder` | `MixedType` | `""` | 保存图像的目标文件夹目录路径 |
| `filename` | `MixedType` | `"screenshot.png"` | 输出保存的图像文件名（含扩展名） |
| `image` | `MixedType` | `""` | 上游流程生成的 Image 图像对象引用 |

## 4. 输出
- 返回保存是否成功布尔值（`bool`）。
